# Project plan

## Step 1 - Proposal and GitHub setup

Dates stated in the supplied course handout:

- Initial draft: 22 October, 23:59.
- Final submission: 25 October, 23:59.

The handout does not specify a year or timezone. Confirm the deadline details in SUCourse.

### Repository checklist

- [ ] Create the public repository and verify the link.
- [ ] Include a README with the app title, description, and confirmed group details.
- [ ] Include a Flutter .gitignore and initial commit.
- [ ] Invite all group members as collaborators and ensure invitations are accepted.
- [ ] Verify instructor and assigned TA can access the repository.

### Proposal checklist

Prepare a 1-2 page PDF containing:

- [ ] Application title, group number, member names, and student IDs.
- [ ] App overview: the problem, proposed solution, and intended users.
- [ ] Core features, with optional features listed separately.
- [ ] Data requirements, including database and external API needs.
- [ ] Potential technical challenges.
- [ ] Step 1 coordinator and a task allocation table covering all members.
- [ ] The public repository link.

Share the draft proposal and repository link with the assigned TA, incorporate feedback, and submit one PDF per group through SUCourse. All group members should review the final submission.

No application implementation is required at this stage.

## Later project steps

Add requirements and dates when the corresponding course instructions are released. Keep tasks in GitHub Issues, record each step's coordinator and responsibilities, and update the README as the app evolves.
